# Attendance

Teachers record attendance for active students in an active assigned class.
Records support `PRESENT`, `ABSENT`, `LATE`, and `EXCUSED` statuses, drafts, and
submission. Admins can review submitted records and export filtered CSV data.

Each attendance record belongs to one lesson and one student. A lesson is
identified by class, date, and required lesson name; multiple named lessons can
exist for one class on one date.
