# Grades

Teachers can enter grades for students in their own active classes. The model
supports partial evaluations at class 7 and class 23, plus Mid-term and Final
test grades.

Letter grades range from `D-` through `A` with no `A+`. Test grades store an
oral letter grade, composition from 0 to 2, and written-test score from 0 to 8;
the written total is composition plus written test, out of 10. Admins can view
grades through class and student review workflows.
